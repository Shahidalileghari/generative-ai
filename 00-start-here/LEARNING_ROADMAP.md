# Learning roadmap
1. Foundations: vectors, probability, loss, gradient descent.
2. Neural networks and representation learning.
3. NLP, tokenization, embeddings, language modeling.
4. Transformers: attention, positional information, decoder blocks.
5. LLM application engineering: prompts, structured output, API boundaries.
6. RAG: ingestion, chunking, embedding, retrieval, grounded generation.
7. Adaptation: instruction tuning, LoRA, evaluation data.
8. Tools and agents: permissions, state, retries, stop conditions.
9. Evaluation and safety: hallucinations, injection, privacy.
10. Deployment: serving, caching, observability, cost controls.
Suggested pace: 10–14 weeks at 1–2 focused hours/day.
